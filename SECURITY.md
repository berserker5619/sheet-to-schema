# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please report privately via
[GitHub security advisories](https://github.com/berserker5619/sheet-to-schema/security/advisories/new)
rather than opening a public issue.

Include the affected version, what an attacker can achieve, and a reproduction if you have one.
